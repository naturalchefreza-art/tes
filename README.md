# Armania — Building Tools & Equipment Store

A production-quality e-commerce storefront for building tools and equipment.
Vite + React + Tailwind CSS. Product data, cart, wishlist and blog content are fully client-side.

## Development

```
docker compose -f docker-compose.base44.yml up -d
```

Then open http://localhost:3000.

## Manual (no Docker)

```
npm install
npm run dev
```
